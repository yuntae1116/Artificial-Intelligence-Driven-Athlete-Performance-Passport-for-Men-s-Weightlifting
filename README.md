# AI-Driven Athlete Performance Passport (Weightlifting) – Code & Data


This repository contains Python modules converted from the original Jupyter notebooks and a _synthetic_ dataset derived from a private raw file. The code implements a typical pipeline for performance-based anti-doping analytics:
- Preprocessing and feature engineering
- RNN/GRU/LSTM baseline for longitudinal performance prediction
- XGBoost-based classification with SHAP explanation

> **Important:** The dataset included here is **synthetic** (fake) and **does not** contain any personally identifiable or proprietary raw data. It was generated to mimic schema and basic statistics for reproducibility, while protecting privacy.

## Notebooks → Python

Each `.py` file was generated by stripping Jupyter magics and shell lines and concatenating code cells with markers like `# ---- Cell k ----`. The files are meant to be imported as modules. Running a module directly will print a short message; you should expose and call functions as needed.

## Data

- **Original raw file (private, not included):** `lifting_npj_raw.CSV`  
- **Included synthetic file:** `lifting_npj_fake.csv` with identical columns and similar distributional properties but with anonymized/perturbed values.

### How we synthesized the data

1. **Schema preservation:** We inspected column names, types, and basic summary stats.  
2. **Numeric variables:** Added Gaussian noise (≈15% of original dispersion), enforced non-negative floors for weight/total-like variables, and clamped year-like variables to integer ranges with nullable integers.  
3. **Categorical variables:** Replaced each unique category by a stable pseudo-token (e.g., `NATION_0001`), preserving cardinality and approximate frequency.  
4. **Row shuffling:** Shuffled rows to further decouple from any original ordering.

This procedure **does not allow** reconstruction of any original row while preserving enough structure to run the pipeline.
